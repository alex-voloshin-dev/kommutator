# Client integration assets

Start with the [client installation guide](../docs/INSTALL.md). The directories here are
source/manual templates; they are not standalone marketplace artifacts and require the
configured source runtime. The [exporter](../docs/PLUGIN_BUILD.md) produces local catalogs
and self-contained plugins with a bundled runtime and private setup form.

See [Claude details](claude-code/README.md) and [Codex details](codex/README.md) for vendor
identity, hooks and evidence boundaries. Do not install manual and bundled hooks together.
